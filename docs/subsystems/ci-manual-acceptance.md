# Windows 本地 app 验收清单

使用 `npm run app:build:local` 构建的 Windows 调试 app，或已验证提交对应的发布制品。
记录提交、构建类型、Windows/WebView2 版本和 DPI；只有实际操作过的项目才可勾选。
首次实现、修改相关交互或交付试用版本时执行，不要求每个 PR 都完整重复手测。

- [ ] 各页下拉菜单可以打开并选择，选中后对应内容实际变化；没有被父容器裁切或遮挡。
- [ ] 从非默认宽高开始，分别左右、上下拖动窗口，缩小和放大后控件仍可用，布局跟随变化。
- [ ] 设置页面高度不足时可以用滚轮到达最底部设置并操作；高度足够时没有多余纵向滚动。
- [ ] 暂停、技能、撤退键修改后重新打开设置及重启 app 仍保持；无效键名得到错误而非静默接受。
- [ ] 进入整理页自动按需增高；在整理页改变宽高后退出，恢复进入前的宽和高；连续进入退出两次不累积改变。
- [ ] Console 前台 H 打开整理页、Ctrl+S 导出；在文字输入控件中输入 H 不应意外切页。
- [ ] 最小化进入托盘，托盘恢复窗口；关闭窗口退出程序。

**未实现而不是待测通过：** P/H/Ctrl+S/K 的自定义配置。当前设置页只展示这些固定快捷键，
不能用游戏执行键位设置的通过结果代替；后续实现配置和注册后再补对应自动化与实机验收。

WGC、真实录屏识别、游戏前台 P/K、取消输入释放、安装升级等项目继续按
[Console 集成验收](console-acceptance.md) 记录。本次基础 UI 验收不自动启用真实代理输入。
