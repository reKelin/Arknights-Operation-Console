# 开发路线

版本号表示产品里程碑，不表示本轮已经发布。功能 PR 按独立能力交付，不为每个 PR 单独发版；只有对应验收完成后才能把里程碑标记为稳定。

| 版本 | 交付主题 | 验收条件 |
|---|---|---|
| v0.1.0 | Console 界面、可信计时与手动录轴 | 最新紧凑三模式 UI 接入真实状态；可信计时、P 记录、H 整理及导出可用；WGC 优先无黄框捕获并提供明确回退提示 |
| v0.1.1 | 代理指挥与接管续录 | 部署、技能和撤退均在暂停事务中执行；K 接管取消在途输入并保持暂停；按本局已确认回执保留旧轴前缀，人工续录生成会话内新版本 |
| v0.1.2 | 录屏提取与接续校对 | 从原始 PTS 提取实际操作区间候选；人工补全参数和确认时间后创建新轴；可与接管版本的已执行前缀对齐合并，旧版本保持不变 |
| v0.2.0 | 四项核心能力稳定交付 | 手动录轴和录屏分析两条完整攻略循环通过官方 PC 客户端实机验收；异常处理、安装升级和支持边界有可复核证据 |

## 发布门槛

- **v0.1.0** 必须覆盖倍速、减速、暂停、满费、费用锚点恢复、丢帧、离关、人工/代理时钟交接，以及 1100/860 宽度、深浅主题、长文本和快捷键作用域。
- **v0.1.1** 必须覆盖三类暂停操作、同帧稳定顺序、目标帧跨越、失焦、画面过期、尺寸变化、输入取消，以及动作之间和动作中接管、同帧已执行项保留、时间连续和不确定回执确认。
- **v0.1.2** 必须覆盖多区段、变帧率、缺失片段、源时间对齐、重复候选、冲突决议、新建录屏轴和接管后接续合并。未分类、参数缺失或时间未确认的候选不得导出或用于代理。
- **v0.2.0** 必须完成“人工录轴 → 代理 → K 接管 → 人工续录 → 新轴代理”和“录屏提取/接续 → 校对 → 新轴代理”两条实机循环，并验证从旧 Runner 安装升级后沿用 bundle identifier、配置目录和用户设置。

## 当前证据边界

仓库内实现和静态检查不等于版本发布或稳定验收。录屏识别准确率、真实键鼠/触控执行、官方 PC 客户端两条完整循环、安装包升级和启动验收都需要 Windows 实机证据；缺少这些证据时，v0.2.0 仍保持未验收状态。
