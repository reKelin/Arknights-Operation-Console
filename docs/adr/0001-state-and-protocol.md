# ADR 0001：Rust 权威状态与协议分层

状态：已采纳。本文归纳当前约束及已有设计，不新增功能承诺。

## 背景与决定

时钟、录轴、导出和真实输入必须共享同一份状态与安全门。Rust 持有权威状态和副作用，React 只通过生成的 Tauri 绑定提交命令并消费快照，避免界面与执行器分别判断同一操作是否可执行。

AxisLink v2 仅表达 deploy、skill、retreat 玩家操作，由 JSON Schema 生成跨语言类型；运行策略、候选时间证据、会话版本和回执属于内部模型。内部 Tauri 绑定从 Rust 类型生成，不以交换协议承载应用状态。

## 代价与约束

修改协议或命令类型需同步生成代码并检查漂移。草稿允许不完整，但导出和代理共用就绪门禁；方便编辑不能降低协议有效性要求。

## 已替代与不采用的方案

早期 Demo 的 AxisLink v1 已由 v2 替代，当前导入明确拒绝 v1。不要重新引入前端权威计时/调度器，或把提醒、暂停策略与内部会话信息塞入 AxisLink。
