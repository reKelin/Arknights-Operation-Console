# ADR 0002：来源时间、独立时钟与执行证据

状态：已采纳。本文归纳现有时钟与执行约束。

## 背景与决定

人工操作包含减速选中、部署与不确定时间范围；代理执行需要在可信暂停边界产生输入。HumanClock 与 ProxyClock 独立持有状态，共享无状态时间换算；交接只传递有证据支持的时间值，不携带调度历史。

实机使用 WGC 来源时间，录屏使用原始 PTS/time base。缺帧或时间不连续要显式降低可信度。代理事务同时需要时间未推进的证据与动作结果证据；输入 API 成功只能说明输入已发送。

## 代价与约束

满费、费用区域遮挡或结果不清晰时可能无法自动确认，必须停止并保留 uncertain 供人工处理。K 接管等待取消收尾，只按本次运行的有序回执保留前缀，不能以帧大小猜测哪些操作已经成功。

## 已替代与不采用的方案

早期录屏监控按固定 30 Hz 重采样的方案已被保留原始展示帧与 PTS 的设计替代。不能以平均帧率、主机回调时间或 UI 显示帧补造权威时间；不能把已发输入直接记为成功，也不能恢复后补发错过事件。
