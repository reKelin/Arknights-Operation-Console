# 交互 Demo 需求

- REQ-DEMO-001：Demo 必须使用模拟源自动进入关卡并以 30 tick/s 推进。
  - AC-DEMO-001：启动后无需手动开始计时；模拟离关后计时停止并可自动开始下一轮。
- REQ-DEMO-002：窗口必须复现已确认的紧凑 UI。
  - AC-DEMO-002：默认约 900×236、高度固定、宽度可调、默认置顶；不显示游戏画面、侧栏、队列或独立浮窗。
- REQ-DEMO-003：时间轴必须为单轨并支持横向操作。
  - AC-DEMO-003：支持滚动、缩放、当前帧游标、已走区段高亮、双击新增、拖动改帧和删除。
- REQ-DEMO-004：Demo 必须支持实时手动录轴。
  - AC-DEMO-004：窗口不聚焦时，全局 F1/F2/F3 仍能在当前帧新增部署、技能、撤退操作点。
- REQ-DEMO-005：每个操作点必须保留后续执行所需参数。
  - AC-DEMO-005：F1/F2/F3 和双击新增先创建允许缺少执行参数的内部草稿；右键标点可补全类型、帧、干员、格子、朝向和说明；未补全草稿不得导出为合法 AxisLink。
- REQ-DEMO-006：Demo 必须支持 AxisLink JSON 导入导出。
  - AC-DEMO-006：合法文件往返不丢字段；非法版本、类型、帧或载荷返回中文结构化错误。
- REQ-DEMO-007：提醒与执行策略必须独立于轴文件。
  - AC-DEMO-007：标题栏“轴”菜单可选择提前提示音或到点模拟暂停；模拟暂停后出现明确的“继续模拟”入口；不得把策略写入 AxisLink。
- REQ-DEMO-008：Demo 不得产生游戏副作用。
  - AC-DEMO-008：不存在游戏捕获、进程访问或输入注入依赖；所有执行只显示 dry-run 结果。
- REQ-DEMO-009：窗口生命周期必须符合轻量工具定位。
  - AC-DEMO-009：标题栏“视图”菜单可以关闭默认置顶；最小化进入托盘；关闭窗口退出程序。
- REQ-DEMO-010：跨语言类型必须自动生成。
  - AC-DEMO-010：AxisLink 由 JSON Schema 生成 Rust/TypeScript；Tauri 命令由 Rust 类型生成包含 `invoke` 调用的 TypeScript 绑定，前端不得手写命令字符串，CI 检查生成结果。
- REQ-DEMO-011：编辑内容只保存在内存和显式导出的文件中。
  - AC-DEMO-011：Demo 不实现自动恢复草稿或本地数据库。
- REQ-DEMO-012：编辑轴后必须确定性重建调度状态。
  - AC-DEMO-012：任何新增、替换、移动、删除或导入完成后，当前帧及以前的事件视为已处理，未来事件保持待触发；过去事件移到未来后可以在新帧触发，未来事件移到过去后不得立即执行。
