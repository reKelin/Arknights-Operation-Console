# 代理执行设计

## 状态与安全门

Rust 持有 `ProxyState`、急停代次、活动触点和只读执行记录。React 只能请求确认或急停。开启前必须存在窗口监控、关卡匹配、可信时钟、完整 v2 轴和当前关卡投影；任一条件失效立即解除。

F12 与界面急停共用一个命令。事件到期后先组成同帧稳定批次，再逐项执行；失败项及后续项记为失败并消费，恢复后不得补发。

## 坐标与输入

窗口客户区坐标经 `ClientToScreen` 转为物理屏幕坐标。触摸序列固定为 `DOWN → UPDATE... → UP`；失败时补发 `CANCELED | UP`。部署从唯一头像卡位拖到侧视格子投影，再向朝向短划。技能和撤退按正视投影选择单位，并触摸对应操作按钮。

投影采用 Arknights-Tile-Pos 的公开 MIT 矩阵参数和按关卡 `view`/格子高度数据，但短代码仍使用 Runner 的“字母是行、数字是列”约定。

## 视觉资源

生成的干员目录只包含 ID 和中文名。头像与关卡投影文件固定来源版本并按轴需要下载到缓存，不提交游戏素材。部署栏先检测槽位，再把每个灰度头像 ROI 与目标干员全部皮肤模板比较；唯一超过阈值且领先次优结果时才可执行。

## UI

标题栏显式调用 `startDragging`。录屏轨迹点改为圆形；同帧操作保持相同横坐标，仅改变纵向层级。普通滚轮修改 `scrollLeft`，Alt+滚轮改变缩放并保持指针所指帧的位置。

“代理执行”使用两次确认并显示风险、就绪条件、急停入口和最近事务记录。
