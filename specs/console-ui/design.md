# Console 界面设计

当前界面结构与能力以 [原型工作流重构](../console-workflow/design.md) 为准。

## 页面结构

单窗口保留三类页面状态：工作台、设置和轴编辑。工作台顶栏直接切换人工录轴、录屏分析和代理指挥；设置与编辑从工作台进入并提供明确返回入口。工作台使用约 280 px 高度，编辑页不限制为紧凑高度。

React 只消费 `RunnerSnapshot` 并调用已有生成绑定。界面不构造监控、计时、录屏或代理成功状态。尚无后端语义的录屏候选和暂停代理显示为不可用能力。

## 时间轴

时间轴保持单轨和贯穿式刻度。可见帧数是唯一缩放状态，范围为 40–18,000 帧。主刻度从固定候选中选择，并固定分成五个小刻度；帧与像素换算保留在 `timelineMath.ts` 中接受 Vitest 检查。

操作点继续支持选择、拖动、右键编辑和双击新增。形状只编码操作类型，颜色用于已走、未来、未完成和选中状态。

## 当前能力边界

- 人工录轴连接 `setRecording`，P 书签由现有全局入口记录，H 打开独立编辑页。
- 录屏分析连接 `analyzeRecording`，只展示现有时间轨迹和关卡区段。
- 代理模式仅解释后续能力，执行按钮禁用；不得调用现有实验性 `requestProxyExecution`。
- Ctrl+S 使用现有导出命令和系统保存对话框。
